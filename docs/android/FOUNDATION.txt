build_foundation CHECKOUT ANDROID_WORK JDK_HOME
All three arguments must be absolute paths. ERNOS_COMPILER can override the
installed compiler path. The builder checks the native link for undefined
symbols, aligns the APK, signs it using a local debug key and verifies signing.
Output: ANDROID_WORK/apk/echolite-dev.apk

Install with adb install --no-incremental -r, then launch
  dev.echolite.android/android.app.NativeActivity
The dev package has no access to the Mac's private memory or credentials.
Application source remains EP. Manifest XML is Android packaging metadata;
compiler-generated C and third-party library C are native build artifacts.

Port-specific dependencies and defects addressed:
- ARM64 Android open flags differ from generic Linux in O_DIRECTORY/O_NOFOLLOW.
- Android struct stat, errno, monotonic clock, socket address, socket options,
  nonblocking errno and SIGPIPE suppression differ from Darwin.
- SQLite must enable FTS5 and SQLITE_ENABLE_MATH_FUNCTIONS for vector recall.
- Android Bionic heap pointers can have a top-byte tag. The Ernos runtime must
  recognize tagged raw strings in automatic conversion and map keys without
  disabling memory tagging. The exact-text SQLite regression passes on-device.
  The initial diagnostic state retained a bad Me revision and vectors before
  this fix; it is not the validated fixture or future application data.

Build compiler requirement:
Use ERNOS_COMPILER pointing at the Ernos build with ep_android_string_byte in
its runtime. The Android builder rejects an older compiler to prevent silent
text corruption. Compiler regression/self-hosting gate logs are kept locally;
completion of those gates must be checked before publishing the compiler patch.
