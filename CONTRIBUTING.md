# Contributing

EchoLite is under active development. Small, concrete improvements are welcome.

- Describe the observable problem and expected behavior.
- Keep authored runtime/UI/test code in Ernos Plain.
- Add focused validation for changed behavior; don't rerun unrelated expensive benchmarks.
- Preserve memory provenance, history and explicit forgetting behavior.
- Keep personal data, credentials, downloaded assets and generated binaries out of commits.
- Include a screenshot or short reproduction for visible UI changes.
- Distinguish implemented behavior from proposed work in documentation.

Read [setup](docs/SETUP.md), [development](docs/DEVELOPMENT.md) and [current limits](docs/STATUS.md) before proposing architectural changes.

EchoLite's authored code is MIT-licensed. Third-party dependencies, model weights and reference data retain their own licenses.
